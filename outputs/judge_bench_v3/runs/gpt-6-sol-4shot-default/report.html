评测条件

训练集7200条和测试集800条都覆盖400个 scenario，每个 scenario 为18条训练、2条测试。本结果衡量固定 benchmark 内的专用 judge，不能解释为未见 scenario 的泛化表现。

示例只来自7200条训练集，选择过程不读取目标标签，也不按示例标签挑选。每条优先选4个其他 checkpoint；772条提供4个不同 checkpoint，另外28条提供3个其他 checkpoint 的4条不同标注。全部排除目标 checkpoint 的所有模型结果。background 只提供一次。示例的未来事件不作为目标已观测证据。

GPT 使用同 scenario 的人工示例，Qwen v3 的基座/训练后评测使用无示例输入。两者测试目标相同，但提示信息不同，因此不能将差值直接解释为纯模型优劣或训练提升。
