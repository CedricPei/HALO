固定数据划分与评测协议

集合条数Scenario 数每模型 / 每领域 / 每 trigger
测试集8004080 / 80 / 200
训练集7,200360720 / 720 / 1800

固定 seed=20261010；40 个领域 × trigger 分层各留出 1 个完整 scenario。每个 scenario 的 20 条人工标注一起进入同一集合，选择不依赖人工标签或模型预测。两集合共享 scenario 0 个，共享用户 instance 27 个；这是 scenario 留出，用户背景与部分可复用记录可能共享。

输入与人工页面对齐：background 包含完整的 instance_description、personal_description、scenario_description；另提供 checkpoint prefix、按轮次排序的 retrieval command/result 和 candidate action。保持全部已有证据，不截断 context。人工标签、标注评论和来源信息保存在独立字段中，不进入模型输入。

测试集有 2 组完全相同输入的人工标签存在分歧，标签原样保留。对相同输入给出一致判决时，准确率上限为 99.75%。
